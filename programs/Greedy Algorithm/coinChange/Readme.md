Coin Change / Note Change Problem

You are given an amount V. Now we need to provide a change for V using the following denominations in Indian currency.

We have an infinite supply of each coin or note in the given denominations.

Find the minimum number of coins or notes required to make the change for V.

The available denominations are:

{1, 2, 5, 10, 20, 50, 100, 200, 500, 2000}
Examples

Example 1:

V = 70

Output: 2

50 + 20 = 70

Example 2:

V = 129

Output: 5

100 + 20 + 5 + 2 + 2 = 129

Example 3:

V = 122

Output: 3

100 + 20 + 2 = 122
