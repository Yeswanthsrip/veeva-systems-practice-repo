Sort Array Elements by Decreasing Frequency
Q. You are given an array of n integers. Sort the elements of the array according to the frequency of their occurrence.
The sorting should follow these rules:
Elements with higher frequency should come first.
If two elements have the same frequency, the smaller number should come first.

Ex :-
n=6
{5,4,4,6,5,5}
output :- 5 5 5 4 4 6
