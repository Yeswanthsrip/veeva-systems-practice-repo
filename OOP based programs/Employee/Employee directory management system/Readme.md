Employee Directory Management System
Among organization, there is a need for an efficient way to manage employee records. Every employee is assigned a unique ID. Searching through a standard sequential list like ArrayList can be slow. As the company grows with more number of employees, we design and develop a high-performance employee directory system.
Functional Requirements:
Data mapping:
Mapping of a unique employee ID to the set of employee details like name, salary & date of joining.
Fast insertion
Record removal
Instant retrieval:
Given an employee ID, retrieve the details of the employee quickly.
Data modification:
Update employee details based on employee ID.
Traversal:
Provide a mechanism to iterate through the entire active employee directory and access the details.
